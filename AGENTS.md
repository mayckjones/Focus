# Convenções de entrega

Após concluir qualquer alteração neste projeto, a resposta final deve sempre incluir:

## Título do commit

Uma frase curta, objetiva e no imperativo, pronta para usar no GitHub Desktop.

## Descrição do commit

Um resumo conciso do que foi alterado e, quando relevante, o motivo da alteração.

## Arquivos alterados

Liste os arquivos modificados e explique brevemente a função de cada mudança.

## Validações

Liste os testes, verificações ou validações executados e indique se foram aprovados.

Não execute `git commit` nem `git push` automaticamente. Apenas prepare o título e a descrição para que o usuário possa usá-los no GitHub Desktop.
